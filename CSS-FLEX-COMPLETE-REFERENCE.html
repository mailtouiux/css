1 flex-what.html

What is a Flex Container?

Parent property

Activate Flexbox by setting display: flex on the parent. The parent becomes a "flex container," and its direct children become "flex items."

The HTML

1.flex-what.html
<ul> <!-- Parent Element -->
  <li>1st child</li>
  <li>2nd child</li>
  <li>3rd child</li>
</ul>

The CSS — Two Ways to Activate Flex

1.style.css
/* Flex Container => Parent */
ul {
  background-color: lightslategray;
  padding: 20px;

  /* Flex Container Properties */
  display: flex;
  /* display: inline-flex; — acts inline but children flex */
}

/* Flex Items => Children */
li {
  list-style: none;
  color: white;
  background-color: #20b2aa;
  padding: 10px;
  margin: 20px;
  width: 100px;
}
display: flex — children line up on the main axis
→ Main axis (horizontal, default)
↓ Cross axis (vertical)
  • 1st child
  • 2nd child
  • 3rd child

The Two Axes — Most Important Concept

ℹ
Remember these 4 points: main-start, main-end (along main axis) and cross-start, cross-end (along cross axis). All flex alignment refers to these 4 points.
✓
Best practice: Use Flexbox for 1D layouts (a row of nav items, a card with horizontal content). Use Grid for 2D layouts (page sections with rows AND columns).
ℹ
display: flex vs inline-flex: flex takes full width (block-like), inline-flex takes only its content width (inline-like). Both make children flex.
2 flex-why.html

Why Use Flexbox?

Parent property

Real-world example showing why Flexbox solves common layout problems — easy alignment, distribution of space, and natural responsiveness.

The Problem Flex Solves

Before Flex, lining up sections side-by-side required floats, inline-blocks, or table layouts — all with quirks. Flex makes it trivial:

The HTML

2.flex-why.html
<section class="child-1">
  <div class="content">
    <h2>Section 1</h2>
    <p>Lorem ipsum...</p>
  </div>
</section>
<!-- Section 2 and Section 3 (same structure) -->

The CSS

2.style.css
/* Body becomes the flex container */
body {
  display: flex;
  flex-wrap: wrap;   /* responsiveness — wraps to next row */
}

section {
  width: 20rem;
  background-color: lightslategray;
  padding: 1.5rem;
  margin: 1rem;
  color: white;
}
3 sections side-by-side, naturally responsive (wraps when narrow)
→ Main axis
↓ Cross axis (wraps here)

Section 1

Lorem ipsum dolor sit amet consectetur adipisicing elit.

Section 2

Lorem ipsum dolor sit amet consectetur adipisicing elit.

Section 3

Lorem ipsum dolor sit amet consectetur adipisicing elit.

★
Real-world wins: Navbars, card rows, button groups, centered content (vertical + horizontal), equal-height columns, and natural responsive layouts.

9 order.html

order

Child property

Reorders flex items visually without changing the HTML. Default is 0. Lower numbers come first, negative numbers come before 0.

This section uses :nth-child(N) — a built-in CSS pseudo-class that picks the Nth child. Example: li:nth-child(2) = the 2nd <li>. See the 📖 PSEUDO-CLASSES tab for full reference.

STEP 1 — Normal order (no order applied)

HTML — order.html
<ul>
  <li>1st Child</li>
  <li>2nd Child</li>
  <li>3rd Child</li>
  <li>4th Child</li>
  <li>5th Child</li>
  <li>6th Child</li>
  <li>7th Child</li>
  <li>8th Child</li>
</ul>
CSS — basic flex, no order
ul {
  display: flex;
}
/* No order property — items appear in HTML order */
RESULT — items appear 1, 2, 3, 4, 5, 6, 7, 8 (same as HTML)
  • 1
  • 2
  • 3
  • 4
  • 5
  • 6
  • 7
  • 8

STEP 2 — Apply order to specific items

HTML — UNCHANGED (still 1 to 8)
<!-- Same HTML, no changes -->
<ul>
  <li>1st Child</li>
  <li>2nd Child</li>
  ... 8 items in HTML order ...
</ul>
CSS — 9.style.css (apply order)
ul { display: flex; }

/* Negative values → move items EARLIER (before default 0) */
li:nth-child(2) { order: -2; }   /* item 2 → very first */
li:nth-child(8) { order: -1; }   /* item 8 → second */

/* Items 1, 4, 7 have no order set → default 0 */

/* Positive values → move items LATER (after default 0) */
li:nth-child(3) { order: 1; }
li:nth-child(6) { order: 2; }
li:nth-child(5) { order: 5; }
RESULT — visual order is now: 2, 8, 1, 4, 7, 3, 6, 5

How the sorting works

ℹ
How sorting works: Items are sorted by order value (lowest first). Items with the same order keep their HTML order. Default order = 0.
!
Accessibility note: Screen readers follow HTML order, NOT visual order. Don't use order for content where reading sequence matters (like article paragraphs).
★
Real-world use: Showing a "Featured" item first on desktop but keeping it last in mobile HTML for SEO. Or putting a logo in the middle of a navbar via order.
10 flex-grow.html

flex-grow

Child property

Defines how much an item grows relative to siblings when there's extra space. Default is 0 (don't grow).

This section uses :first-child and :nth-child(N) — pseudo-classes that pick specific items by position. li:first-child = the 1st <li>. See 📖 PSEUDO-CLASSES tab.

The HTML

10.flex-grow.html
<ul>
  <li>1st Child</li>
  <li>2nd Child</li>
  <li>3rd Child</li>
  <li>4th Child</li>
</ul>

The CSS

10.style.css
ul { display: flex; }

/* Default: flex-grow: 0 (items don't grow) */

li:first-child { flex-grow: 1; }     /* gets 1 share of leftover */
li:nth-child(3) { flex-grow: 3; }     /* gets 3 shares (3× more) */
Item 1 grows 1×, Item 3 grows 3× (others don't grow)
  • 1 (grow:1)
  • 2
  • 3 (grow:3)
  • 4

How flex-grow Math Works

ℹ
How math works: If 4 items + extra space, item with grow:1 takes ¼ of that extra space, item with grow:3 takes ¾. The ratio matters, not absolute values.

Child property

flex (Shorthand)

Child property

Shorthand for flex-grow, flex-shrink, and flex-basis in one line.

The HTML

13.style.css

  flex-grow: 1;
  flex-shrink: 0;

align-self

Child property

Like align-items, but applied to ONE specific item — overrides the parent's alignment for just that item.

Uses :first-child to target one specific item. See 📖 PSEUDO-CLASSES tab.

6 Possible Values

autoDefault — inherits align-items
flex-startTop of cross axis
flex-endBottom of cross axis
centerCenter on cross axis
stretchFills cross axis
baselineText baseline aligned

The HTML

14.align-self.html
<ul>
  <li>1st Child</li>
  <li>2nd Child</li>
  ... 8 items total ...
  <li>8th Child</li>

⚠ Common Mistakes to Avoid

The most frequent Flexbox mistakes and how to fix them.

!
1. Confusing main vs cross axis. When direction is row, main = horizontal. When direction is column, main = vertical. justify-content always means "main axis."
!
2. align-content doing nothing. It only works with flex-wrap: wrap AND multiple rows. Single-row containers ignore it — use align-items instead.
!
3. Using order for important content. Screen readers follow HTML order, not visual order. Don't reorder critical reading content with order.
!
4. Forgetting that flex-shrink defaults to 1. Items shrink by default! Set flex-shrink: 0 on logos/sidebars that should keep their size.
!
5. align-items with no container height. Vertical alignment needs a container with height OR items with different heights — otherwise there's nothing to align within.
!
6. Using Flex for 2D layouts. Flex is 1D. If you need rows AND columns aligned together, use Grid.
!
7. Setting width vs flex-basis. Inside a flex container, prefer flex-basis — it cooperates with grow/shrink. width can be overridden in unexpected ways.
