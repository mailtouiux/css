Understanding Grid Lines

Grid creates invisible numbered lines between every column and row. For N columns, there are N+1 vertical lines. For N rows, there are N+1 horizontal lines.

ℹ
Why this matters: When you write grid-column: 1 / 3, you're saying "start at line 1, end at line 3." Lines, not cells. This is the #1 thing beginners miss.
✓
Best practice: Always set both columns AND rows when you start. Use Grid for full-page layout, Flexbox for components inside.
3 col-row-gap.html

Gap, Row Gap & Column Gap

Parent property

Add space between cells without using margins. Cleaner, more predictable, and respects all alignment.

The HTML

3.col-row-gap.html
<div class="parent">
  <div class="item">A</div>
  <div class="item">B</div>
  <div class="item">C</div>
</div>

The CSS — Three Properties, One Job

3.style.css
.parent {
  display: grid;
  grid-template-columns: repeat(3, 1fr);

  column-gap: 30px;       /* horizontal space (between columns) */
  row-gap:    10px;       /* vertical space (between rows) */

  /* Shortcut */
  gap: 10px;               /* equal: row + column */
  gap: 10px 30px;          /* row-gap, column-gap */
}

4 repeat-fr.html

The repeat() Function & The fr Unit

Parent property

Two essential time-savers — repeat() for repetition and fr for fluid sizing.

Uses repeat() (CSS function) and 1fr (special unit). See 📖 PSEUDO-CLASSES tab.

The HTML

4.repeat-fr.html
<div class="parent">
  <div class="item">1fr</div>
  <div class="item">1fr</div>
  <div class="item">1fr</div>
  <div class="item">1fr</div>
</div>

The CSS — repeat() Function

4.style.css
/* Long way */
grid-template-columns: 1fr 1fr 1fr 1fr;

/* Short way — exactly the same */
grid-template-columns: repeat(4, 1fr);

/* Mix repeat with other values */
grid-template-columns: 200px repeat(3, 1fr) 200px;

/* Repeat patterns */
grid-template-columns: repeat(3, 100px 50px);  /* = 100px 50px 100px 50px 100px 50px */

Think of fr as "shares of leftover space" after fixed sizes and gaps are subtracted.

6 span-grid-item.html

Spanning Grid Items

Child property

Use the span keyword to stretch items across multiple cells without doing line-number math.

Uses span — a CSS keyword meaning "stretch across N tracks." See 📖 PSEUDO-CLASSES tab.

The HTML

6.span-grid-item.html
<div class="parent">
  <div class="item wide">span 2 cols</div>
  <div class="item tall">span 2 rows</div>
  <div class="item">D</div>
  <div class="item">E</div>
  <div class="item">F</div>
  <div class="item">G</div>
</div>

The CSS — Three Ways to Use span

6.style.css
/* 1. Just span N cells (auto-placement decides start) */
.wide { grid-column: span 2; }
.tall { grid-row:    span 2; }

/* 2. Start at a specific line, then span */
.x { grid-column: 1 / span 3; }  /* line 1 → 3 cells wide */

/* 3. End at a specific line, span backward */
.y { grid-column: span 3 / 5; }  /* 3 cells wide, ending at line 5 */

Naming Grid Lines

The CSS — Named Lines (Square Brackets)

  grid-column: sidebar-start / sidebar-end;
}
.content {
  grid-column: main-start / main-end;

How names map to line numbers

ℹ
Names ARE the line numbers — just renamed. grid-column: start / end does the EXACT same thing as grid-column: 1 / 4. Pick whichever is clearer for you.
ℹ
Multiple names per line: A single line can have multiple names — useful when a line is both "the end of one area" and "the start of another."
!
Beginner advice: Skip line names while learning. Numbers work for 95% of layouts. Come back to names when building reusable design systems.
8 grid-temp-areas.html

Grid Template Areas ★

Parent (defines areas) Child (places into area)

The most visual layout method. You literally draw your page using words. The MVP property of CSS Grid.

The HTML

8.grid-temp-areas.html
<div class="parent">
  <div class="header">HEADER</div>
  <div class="sidebar">SIDEBAR</div>
  <div class="main">MAIN CONTENT</div>
  <div class="footer">FOOTER</div>
</div>

The CSS — Three-Step Recipe

8.style.css
.parent {
  display: grid;
  grid-template-areas:
    "head head head"
    "side main main"
    "side main main"
    "foot foot foot";
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows:    60px 80px 80px 50px;
  gap: 8px;
}

.header  { grid-area: head; }
.sidebar { grid-area: side; }
.main    { grid-area: main; }
.footer  { grid-area: foot; }
Real webpage layout — header, sidebar, main, footer

How named areas map to grid lines

The 4 Rules You Must Follow

  • Equal columns per row: Each string must have the same number of words.
  • Repeat to span: Same name in adjacent cells = one merged area.
  • Empty cells: Use a single dot . (or multiple dots ...).
  • Rectangles only: Repeated names must form a rectangle — never an L-shape or T-shape.
★
Mobile-first responsive trick: Just redefine grid-template-areas in a media query. The same HTML stays — only the layout changes.
✓
Best practice for beginners: Master this method first. It handles 95% of real-world layouts and is by far the easiest to read 6 months later.

13 max-min-minmax.html

min-content, max-content & minmax()

Parent property (used in template-columns/rows)

Smart sizing values that respond to content size and viewport — essential for responsive layouts.

Uses minmax() (CSS function) and min-content / max-content keywords. See 📖 PSEUDO-CLASSES tab.

Three Sizing Values

min-contentAs small as content allows (longest word)
max-contentAs wide as content needs (no wrapping)
minmax(a, b)At least 'a', at most 'b'

The HTML

13.max-min-minmax.html
<div class="parent">
  <div class="item">min 100, max 1fr</div>
  <div class="item">min 200, max 2fr</div>
  <div class="item">min 100, max 1fr</div>
</div>

The CSS — minmax() in action

13.style.css
/* Each column has a floor and ceiling */
grid-template-columns:
  minmax(100px, 1fr)      /* never below 100px, can grow to 1fr */
  minmax(200px, 2fr)
  minmax(100px, 1fr);

/* Common use: prevent columns from squishing */
grid-template-columns: minmax(0, 1fr) minmax(0, 2fr);
Columns respect their min and max — they won't squish or stretch beyond limits

How minmax() sizes columns + grid lines

✓
Best practice: minmax() is your responsive workhorse. Set minmax(0, 1fr) when content overflows — the 0 minimum allows shrinking below content size.

⚠ Common Mistakes to Avoid

The most frequent CSS Grid mistakes and how to fix them.

!
1. Confusing rows and columns. Rows go HORIZONTALLY (lying down → ━━━), columns go VERTICALLY (standing up → ┃).
!
2. Mixing up items vs content. justify-items = each item in its cell. justify-content = the whole grid in its container.
!
3. Using % instead of fr. Percent doesn't account for gaps; your math will break. Use fr always.
!
4. Forgetting that line numbers count LINES, not cells. grid-column: 1 / 3 spans 2 cells (line 1 to line 3).
!
5. Using margins on grid items. Always use gap instead. Margins fight with alignment properties.
!
6. L-shapes in grid-template-areas. Repeated names MUST form a rectangle. The browser silently breaks if you use an L or T shape.
!
7. Using Grid for everything. Use Grid for 2D layouts (page sections). Use Flexbox for 1D (a navbar, a row of buttons inside a card).
