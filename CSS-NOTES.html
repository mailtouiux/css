📊 Note #1 — Alignment Master Table (All 9 Properties)

Every CSS alignment property organized by axis. Color-coded sections make the pattern instantly visible.

# Property Formula Axis Target Set on Flex Grid What it does
⬅️➡️ MAIN AXIS — justify-* (direction items flow)
1 justify-content justify- + -content Main Whole group Parent ✓ ✓ Aligns the whole group along the main axis
2 justify-items justify- + -items Main Each item Parent ✗ ✓ Aligns each item in its cell on main axis
3 justify-self justify- + -self Main One item Child ✗ ✓ Override one item on main axis
⬆️⬇️ CROSS AXIS — align-* (perpendicular to main)
4 align-content align- + -content Cross Whole group Parent ✓ ✓ Aligns wrapped rows as a group on cross axis
5 align-items align- + -items Cross Each item Parent ✓ ✓ Aligns each item on cross axis
6 align-self align- + -self Cross One item Child ✓ ✓ Override one item on cross axis
⤡ BOTH AXES — place-* (shortcut for align + justify)
7 place-content place- + -content Both Whole group Parent ✓ ✓ Shortcut: align-content + justify-content
8 place-items place- + -items Both Each item Parent ✗ ✓ Shortcut: align-items + justify-items
9 place-self place- + -self Both One item Child ⚠ ✓ Shortcut: align-self + justify-self
Why ✗ in Flex? Flex items along the main axis flow naturally — there's no "per-item main-axis position" concept. So justify-items, justify-self, and place-items are ignored in Flex. The ⚠ for place-self means only its align-self part works in Flex.

💬 Each Property in Plain English

A simple one-line description and a memory trick for each property.

1justify-content

Moves ALL items together along the main axis (the direction items flow).

Think: "Where should the WHOLE group sit horizontally?" (in row layout)
2justify-items

Positions EACH item inside its own grid cell, on the main axis. Grid only.

Think: "Where should each individual item sit inside its cell horizontally?"
3justify-self

Moves ONE specific item inside its cell, overriding the parent's setting. Grid only.

Think: "Just THIS item — let me put it somewhere different from the others."
4align-content

Moves the wrapped ROWS as a group on the cross axis. Only works with flex-wrap: wrap.

Think: "Where should the GROUP of multi-line rows sit vertically?"
5align-items

Positions EACH item vertically (cross axis) inside its row.

Think: "Where should each item sit vertically — top, center, bottom?"
6align-self

Moves ONE specific item vertically, overriding the parent's align-items setting.

Think: "Just THIS item should sit at a different vertical position than the others."
7place-content

Shortcut for align-content + justify-content — moves the whole group on BOTH axes at once.

Think: "Save typing — center the whole group in both directions with ONE line."
8place-items

Shortcut for align-items + justify-items — positions each item on BOTH axes at once. Grid only.

Think: "The cleanest way to center anything in Grid: place-items: center"
9place-self

Shortcut for align-self + justify-self — moves ONE specific item on BOTH axes at once.

Think: "ONE item rebels against the parent — let it sit anywhere it wants."

🎨 Legend — The 3 Color Groups

Each row group in the table above is color-coded by its axis prefix.

justify-* (Main axis) Controls the direction items FLOW.
In row layout: horizontal (← →)
In column layout: vertical (↑ ↓)
align-* (Cross axis) Perpendicular to the main axis.
In row layout: vertical (↑ ↓)
In column layout: horizontal (← →)
place-* (Both axes) Shortcut for align + justify.
Saves you 1 line of CSS.
Only fully works in Grid.

🧠 Memory Pattern — "JAP"

Once you remember this pattern, all 9 properties become obvious.

🎯 The Formula:

Justify- → MAIN axis
Align- → CROSS axis
Place- → BOTH axes (shortcut)

Add one of these as a target:
• -content → whole group (set on parent)
• -items → each item (set on parent)
• -self → one specific item (set on child)

That's it — 3 prefixes × 3 targets = all 9 properties memorized!
Where to write each one:
• -content or -items → set on the PARENT (container)
• -self → set on the CHILD (the specific item)
