📖 What are Pseudo-classes?

Pseudo-classes are special CSS selectors that pick elements based on their state (hovered, focused, checked) or their position (1st, 2nd, last, etc.) — without needing a class name.

The word "pseudo"

"Pseudo" (pronounced SOO-doh) means "fake" or "pretend." A pseudo-class is like a fake class name the browser provides automatically. You don't write it in HTML — CSS knows it.

TypeStarts withWhat it doesExample
Class.Selects elements with a class.button
Pseudo-class:Selects based on state/position:hover, :nth-child(2)
Pseudo-element::Targets PART of element::before, ::after
Important: All pseudo-class names are fixed by CSS. You can't make up your own. The full list is built into every browser.

🎯 User Action State Pseudo-classes

Trigger styling based on what the user is doing — hovering, clicking, focusing.

:hover stable

Activates when the mouse is over an element.

📄 HTML — applies to:
<!-- Any element — usually buttons or links -->
<button>Hover me!</button>
🎨 CSS:
button:hover {
  background: blue;
  cursor: pointer;
}
Live demo — hover the button
Use: Buttons, links, cards — show interactivity

:focus stable

Activates when an element is focused (clicked or tabbed to).

📄 HTML — applies to:
<!-- Form inputs -->
<input type="text" placeholder="Click me">
🎨 CSS:
input:focus {
  border: 2px solid blue;
  outline: none;
}
Live demo — click in the input
Use: Form inputs — show which field is active

:focus-within stable

Activates when the element OR any of its descendants are focused. Great for highlighting whole forms when typing.

📄 HTML — applies to:
<!-- Container element with focusable children -->
<form>
  <input type="text">
  <input type="text">
</form>
🎨 CSS:
form:focus-within {
  background: #f0f8ff;   /* form turns blue when ANY input inside is focused */
}
Live demo — click any input, the WHOLE form highlights
Use: Highlight whole card/form when user is typing inside

:focus-visible stable

Like :focus, but only shows when the user is using KEYBOARD navigation (Tab key) — NOT when clicking with mouse. Modern accessibility best practice.

📄 HTML — applies to:
<!-- Any focusable element -->
<button>Tab to me using keyboard</button>
🎨 CSS:
button:focus { outline: none; }           /* hide on click */
button:focus-visible { outline: 2px solid blue; }  /* show on Tab */
Use: Better accessibility — keyboard users see focus rings, mouse users don't

:active stable

Activates while an element is being clicked (between mouse-down and mouse-up).

📄 HTML — applies to:
<!-- Any clickable element -->
<button>Click me</button>
🎨 CSS:
button:active {
  transform: translateY(2px);   /* "pressed" effect */
}
Live demo — click and HOLD the button
Use: Click feedback — buttons appear pressed

:visited stable

Matches links the user has already clicked. Browser tracks history.

📄 HTML — applies to:
<!-- Anchor tags -->
<a href="https://example.com">A visited link</a>
🎨 CSS:
a:visited {
  color: purple;          /* visited links turn purple */
}
Privacy note: Browsers limit which properties work with :visited — only colors. JavaScript can't read this state.

:link & :any-link stable

:link = unvisited links only. :any-link = both visited and unvisited.

📄 HTML — applies to:
<!-- Anchor tags -->
<a href="/page">An unvisited link</a>
🎨 CSS:
a:link { color: blue; }           /* unvisited */
a:any-link { text-decoration: underline; }  /* both */

:target stable

Matches the element whose ID matches the URL hash. Useful for in-page anchor highlighting.

📄 HTML — applies to:
<!-- Element with id matching URL hash -->
<section id="part-2">Section 2</section>
<!-- URL: page.html#part-2 --></section>
🎨 CSS:
/* URL: example.com/#section-2 */
section:target {
  background: yellow;        /* highlights jumped-to section */
}
Use: Pure-CSS tabs, lightboxes, anchor highlights without JavaScript

📋 Form Input State Pseudo-classes

Style form inputs based on their state — required, valid, checked, disabled.

:checked stable

Matches checkboxes and radio buttons that are checked, plus selected <option>.

📄 HTML — applies to:
<!-- Checkboxes, radio buttons, and option elements -->
<input type="checkbox" id="t1">
<label for="t1">Toggle me</label>
🎨 CSS:
input[type=checkbox]:checked {
  accent-color: green;
}

/* Style label of checked checkbox using sibling combinator */
input:checked + label {
  color: green;
  font-weight: bold;
}
Live demo — click to toggle
Use: Custom toggles, dark mode toggle without JavaScript

:disabled & :enabled stable

Match form elements based on whether they're disabled or enabled.

📄 HTML — applies to:
<!-- Form inputs with the disabled attribute -->
<input type="text" disabled>
<input type="text">  <!-- enabled by default -->
🎨 CSS:
input:disabled {
  background: #f0f0f0;
  cursor: not-allowed;
  opacity: 0.6;
}
input:enabled {
  background: white;        /* default state */
}
Live demo — disabled vs enabled inputs

:required & :optional stable

Match form fields with the required attribute (or without it).

📄 HTML — applies to:
<!-- Form inputs marked as required (or optional) -->
<input type="text" required>  <!-- has required attribute -->
<input type="text">  <!-- optional -->
🎨 CSS:
input:required {
  border-left: 3px solid red;     /* show required fields */
}
input:optional {
  border-left: 3px solid gray;
}
Live demo — required (red left bar) vs optional

:valid & :invalid stable

Match form fields based on whether they pass HTML5 validation.

📄 HTML — applies to:
<!-- Inputs with validation rules (email, number, pattern, etc.) -->
<input type="email" required>
<!-- valid when format is correct -->
🎨 CSS:
input:valid { border-color: green; }
input:invalid { border-color: red; }

/* Common pattern — only show invalid AFTER user interaction */
input:invalid:not(:placeholder-shown) {
  border-color: red;
}
Live demo — type a valid email vs invalid

:in-range & :out-of-range stable

For numeric inputs with min/max — match values inside or outside the range.

📄 HTML — applies to:
<!-- Number inputs with min/max attributes -->
<input type="number" min="1" max="10" value="5">
🎨 CSS:
/* <input type="number" min="1" max="10"> */
input:in-range { background: lightgreen; }
input:out-of-range { background: pink; }

:read-only & :read-write stable

Match inputs that are read-only or editable.

📄 HTML — applies to:
<!-- Inputs with readonly attribute -->
<input type="text" readonly value="Cannot edit">
<input type="text" value="Editable">
🎨 CSS:
input:read-only { background: #eee; }
input:read-write { background: white; }
Live demo — read-only (yellow) vs editable

:placeholder-shown stable

Matches an input that's currently showing its placeholder (i.e., empty).

📄 HTML — applies to:
<!-- Inputs that show a placeholder (i.e., empty) -->
<input type="text" placeholder="Enter your name">
🎨 CSS:
/* Float-label trick — placeholder visible = label looks like placeholder */
input:placeholder-shown + label {
  transform: translateY(20px);
  font-size: 16px;
}
input:not(:placeholder-shown) + label {
  font-size: 12px;     /* shrink label when input has value */
}
Live demo — placeholder text is styled
Use: Material Design floating labels — pure CSS

:default stable

Matches form elements that are the default in their group (the default selected radio button, the default submit button, etc.).

📄 HTML — applies to:
<!-- Default form element in a group -->
<input type="radio" name="fruit" value="apple" checked>  <!-- default -->
<input type="radio" name="fruit" value="orange">
🎨 CSS:
input[type=radio]:default + label {
  font-weight: bold;        /* highlight original default */
}

:user-invalid modern

Like :invalid, but only after the user has interacted with the input. Better UX than showing red borders before they type.

📄 HTML — applies to:
<!-- Modern inputs (better UX than :invalid) -->
<input type="email" required>
<!-- becomes "user-invalid" only AFTER user types & blurs -->
🎨 CSS:
input:user-invalid {
  border-color: red;          /* only red AFTER user touched it */
}

🌳 Position / Structural Pseudo-classes

Pick elements by their position among siblings — first, last, Nth, etc.

:root stable

Matches the root element (<html>). Used to define CSS variables.

📄 HTML — applies to:
<!-- Always the <html> element -->
<html>  <!-- :root matches this -->
  <body>...</body>
</html>
🎨 CSS:
:root {
  --primary: #3b82f6;
  --gap: 16px;
}
.box { color: var(--primary); }
Use: Theme variables — dark mode, color systems

:empty stable

Matches elements with NO children (no text, no elements). Useful for empty states.

📄 HTML — applies to:
<!-- Elements with absolutely no children (no text either) -->
<div>Has content</div>
<div></div>  <!-- :empty matches this -->
<div>   </div>  <!-- whitespace counts! NOT empty -->
🎨 CSS:
.message-list:empty::before {
  content: "No messages yet";
  color: gray;
}

  <li>1st  ← :first-child</li>
  <li>2nd</li>
  <li>3rd</li>
</ul>
🎨 CSS:
li:first-child { font-weight: bold; }

:last-child stable

Matches an element that is the LAST child of its parent.

📄 HTML — applies to:
<!-- Element that is the last child of its parent -->
<ul>
  <li>1st</li>
  <li>2nd</li>
  <li>3rd  ← :last-child</li>
</ul>
🎨 CSS:
li:last-child { margin-right: 0; }

:nth-child(N) stable

Picks the Nth child by position. "nth" = any number.

📄 HTML — applies to:
<!-- Children at specific positions -->
<ul>
  <li>Item 1</li>
  <li>Item 2  ← :nth-child(2)</li>
  <li>Item 3</li>
  <li>Item 4</li>
</ul>
🎨 CSS:
li:nth-child(2) { color: red; }       /* 2nd item */
tr:nth-child(odd) { background: #f9f9f9; }  /* striped table */
li:nth-child(even) { background: gray; }
li:nth-child(3n) { color: blue; }      /* every 3rd: 3, 6, 9... */
li:nth-child(2n+1) { color: red; }     /* same as odd */
li:nth-child(3n+2) { color: red; }     /* 2, 5, 8, 11... */

:nth-last-child(N) stable

Same as :nth-child but counts from the END.

📄 HTML — applies to:
<!-- Children counted from the end -->
<ul>
  <li>1st</li>
  <li>2nd  ← :nth-last-child(3)</li>
  <li>3rd</li>
  <li>4th</li>
</ul>
🎨 CSS:
li:nth-last-child(1) { color: red; }     /* same as :last-child */
li:nth-last-child(2) { color: blue; }    /* 2nd from end */

:first-of-type stable

First element of its type within its parent.

📄 HTML — applies to:
<!-- First element of its type -->
<div>
  <span>Span</span>
  <p>1st p  ← :first-of-type</p>
  <p>2nd p</p>
</div>
🎨 CSS:
/* HTML: <div><span>A</span><p>1</p><p>2</p></div> */
p:first-child { /* matches NOTHING — <span> is first */ }
p:first-of-type { color: red; }  /* matches first <p> */

:last-of-type stable

Last element of its type within its parent.

📄 HTML — applies to:
<!-- Last element of its type -->
<div>
  <p>1st p</p>
  <p>Last p  ← :last-of-type</p>
  <span>span</span>
</div>
🎨 CSS:
p:last-of-type { margin-bottom: 0; }

:only-of-type stable

Element that's the only one of its type among siblings.

📄 HTML — applies to:
<!-- Only element of its type -->
<div>
  <span>span</span>
  <p>Alone p  ← :only-of-type</p>
</div>
🎨 CSS:
p:only-of-type {
  font-style: italic;
}

:nth-of-type(N) stable

Like :nth-child but counts only elements of the same type.

📄 HTML — applies to:
<!-- Nth element of its type -->
<div>
  <span>span</span>
  <p>1st p</p>
  <p>2nd p  ← :nth-of-type(2)</p>
</div>
🎨 CSS:
p:nth-of-type(2) {           /* the 2nd <p> (ignoring other elements) */
  color: red;
}

:nth-last-of-type(N) stable

Nth of type, counting from the end.

📄 HTML — applies to:
<!-- Nth from end of its type -->
<div>
  <p>1st p</p>
  <p>2nd p  ← :nth-last-of-type(1)</p>
</div>
🎨 CSS:
p:nth-last-of-type(1) { font-weight: bold; }  /* same as :last-of-type */

🔍 Logical Pseudo-classes

Build complex selectors with negation, lists, and parent-aware matching.

:not(...) stable

Picks everything EXCEPT what's inside the parentheses.

📄 HTML — applies to:
<!-- Anything except what's in the parens -->
<ul>
  <li>1st</li>
  <li>2nd  ← matched by :not(:first-child)</li>
  <li>3rd  ← matched</li>
</ul>
🎨 CSS:
li:not(:first-child) { margin-top: 10px; }   /* all li's except first */
button:not(.disabled) { cursor: pointer; }
div:not(.hidden, .removed) { display: block; }  /* multiple */
Live demo — all items EXCEPT the first are yellow
  • 1st (default)
  • 2nd ← yellow
  • 3rd ← yellow
  • 4th ← yellow

:is(...) modern

Matches if element matches ANY of the selectors inside. Reduces repetition.

📄 HTML — applies to:
<!-- Match any of the listed selectors -->
<header><h1>Title</h1></header>
<main><h1>Section</h1></main>
<!-- :is(header, main) h1 → both --></main>
🎨 CSS:
/* Without :is() — repetitive */
header h1, header h2, header h3,
main h1, main h2, main h3,
footer h1, footer h2, footer h3 {
  color: blue;
}

/* With :is() — clean */
:is(header, main, footer) :is(h1, h2, h3) {
  color: blue;
}

:where(...) modern

Same as :is() but with ZERO specificity. Easy to override.

📄 HTML — applies to:
<!-- Same as :is but with zero specificity -->
<h1>Heading</h1>
<!-- :where(h1, h2, h3) — like :is, no specificity --></h1>
🎨 CSS:
:where(h1, h2, h3) {
  color: blue;        /* easy to override later */
}
Use: CSS resets and frameworks — set defaults without specificity wars

:has(...) modern (the parent selector!)

FINALLY a parent selector! Matches an element IF it contains a matching descendant.

📄 HTML — applies to:
<!-- Parent element containing matching child -->
<div class="card">
  <img src="...">  <!-- card:has(img) matches parent --></div>
  <p>Card with image</p>
</div>
🎨 CSS:
.card:has(img) {
  padding: 0;       /* card with image — no padding */
}

form:has(input:invalid) {
  border: 2px solid red;   /* form with any invalid input */
}

li:has(.active) {
  background: yellow;        /* li containing .active */
}
Live demo — card automatically turns red because it CONTAINS .alert

Card with alert

ALERT The parent card turned red automatically!

Normal card

No .alert inside, so no red background.

Game changer: For decades CSS couldn't go "up" the DOM tree. :has() finally lets you style parents based on their children. Browser support: Chrome 105+, Safari 15.4+, Firefox 121+ (Dec 2023).

🌐 Linguistic Pseudo-classes

Match elements based on language and text direction.

:lang(language) stable

Matches elements based on their lang attribute (or inherited from ancestor).

📄 HTML — applies to:
<!-- Element with lang attribute -->
<p lang="fr">Bonjour le monde</p>
<p lang="es">Hola mundo</p>
🎨 CSS:
/* <p lang="fr">Bonjour</p> */
p:lang(fr) { font-family: 'French Font', serif; }
:lang(es) { quotes: '«' '»'; }     /* Spanish quote marks */

:dir(direction) modern

Matches elements based on text direction (left-to-right or right-to-left).

📄 HTML — applies to:
<!-- Element with text direction -->
<p dir="rtl">مرحبا</p>  <!-- :dir(rtl) -->
<p dir="ltr">Hello</p>  <!-- :dir(ltr) -->
🎨 CSS:
:dir(rtl) { text-align: right; }     /* Arabic, Hebrew */
:dir(ltr) { text-align: left; }      /* English, French */

⚙️ CSS Functions

Built-in functions that compute values for properties.

repeat(N, value)

Repeats a value N times. Used in Grid template properties.

grid-template-columns: repeat(4, 1fr);            /* = 1fr 1fr 1fr 1fr */
grid-template-columns: 200px repeat(3, 1fr) 200px;  /* mix */
grid-template-columns: repeat(3, 100px 50px);     /* repeat pattern */

minmax(min, max)

Sets a minimum AND maximum size. Track grows up to max, never below min.

grid-template-columns: minmax(100px, 1fr);
grid-template-columns: repeat(3, minmax(200px, 1fr));

calc(...)

Math inside CSS. Mix different units (+, −, ×, ÷).

width: calc(100% - 20px);
height: calc(100vh - 80px);
font-size: calc(16px + 0.5vw);
Spaces required around + and -: calc(100% - 20px) ✓

var(--name)

Use a CSS variable. Define with --name on :root (or any element).

:root { --primary: #3b82f6; }
.btn { background: var(--primary); }
.box { color: var(--text-color, black); }  /* with fallback */

min() · max() · clamp()

Pick smallest/largest value, or clamp between bounds.

width: min(100%, 800px);       /* whichever is smaller */
width: max(50%, 400px);        /* whichever is larger */
font-size: clamp(14px, 2vw, 24px);  /* min, ideal, max */
Use: Responsive typography without media queries

Magic responsive grids without media queries.

grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
/* Creates as many columns as fit, KEEPS empty ones */

grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
/* Same, but COLLAPSES empty columns (items stretch) */

span N (Grid)

Make an item span N tracks (cells).

.item {
  grid-column: span 2;            /* spans 2 columns */
  grid-row:    span 3;
  grid-column: 1 / span 3;          /* start at line 1, span 3 */
}
