My CSS Grid — The ONE Method to Remember

Method: "Named Areas" (grid-template-areas)

Why this method? You literally draw your layout using words. No counting lines, no math. What you see is what you get.

Step 1 — Make the parent a grid

.parent {
  display: grid;
}

Just turn ON grid mode. That's it.

Step 2 — Draw your layout with words

.parent {
  display: grid;

  /* Draw your page like a picture using names */
  grid-template-areas:
    "header  header  header"
    "sidebar main    main"
    "sidebar main    main"
    "footer  footer  footer";

  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: 70px 150px 150px 60px;
  gap: 10px;
}

Step 3 — Tell each child WHICH area it belongs to

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

Done. The child goes wherever its name is in the picture.

4 Rules — Keep These In Mind

Rule 1: Each row in grid-template-areas must have the same number of columns (same number of words).
Rule 2: To make an area span multiple cells, just repeat the name.
Example: "header header header" = header spans all 3 columns.
Rule 3: Use a . (dot) for an empty cell.
Example: "sidebar . main" = empty space in the middle.
Rule 4: Repeated names must form a rectangle — never an L-shape.

Tiny Units Cheat Sheet (only what you need)

200px  → fixed width
1fr    → takes 1 share of leftover space
2fr    → takes 2 shares (twice as wide as 1fr)
auto   → size based on content
Pro tip: Mix them. grid-template-columns: 200px 1fr 1fr; means "fixed 200px sidebar, then split the rest into two equal pieces."

The Mental Model — Keep this picture in your head

Think of CSS Grid like building a house with rooms:

  • Step 1: Decide how big the house is (columns + rows)
  • Step 2: Name each room on the floor plan (grid-template-areas)
  • Step 3: Tell each piece of furniture which room it goes in (grid-area)
Stick to this method only. Ignore grid-column-start, grid-row-end, line numbers, etc. for now. You can do 95% of real-world layouts with just grid-template-areas. Learn the rest LATER, only when you actually need them.
